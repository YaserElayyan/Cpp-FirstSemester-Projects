# C++ — First Semester

![C++](https://img.shields.io/badge/language-C%2B%2B-00599C?logo=cplusplus&logoColor=white) ![Programs](https://img.shields.io/badge/programs-250-blue) ![Status](https://img.shields.io/badge/status-learning-brightgreen)

A collection of **250 C++ programs** written during my first semester learning to code — organized by topic, from basic I/O all the way to structures, enums, and small mini-projects.

Each program was an exercise while learning a specific concept, so expect some repetition and rough edges — that's part of the learning process. Later attempts at the same exercise (marked `1.1`, `1.2`, etc.) show iteration and improvement.

## 🛠️ How to Compile & Run

Each `.cpp` file is a standalone program. Using [g++](https://gcc.gnu.org/):

```bash
g++ -o program path/to/File.cpp
./program
```

Or open any file directly in an IDE such as Visual Studio, CLion, or VS Code with the C++ extension.
